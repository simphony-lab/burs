# MassTPA — тестовый шот (кубический 3D-стиль)

Вертикальный ролик 720×1280, 30 fps, ~8 с. Читер **brohacker** включает чит MassTPA и рассылает
всем на спавне запросы на телепортацию; игроки в шоке.

Всё собирается кодом: сцена, персонажи, анимация и камеры строятся в Blender (Cycles, мягкие тени,
отражённый свет, размытие фона), чат/ники/подпись и звук накладываются вторым проходом.
Персонажи, скины и текстуры блоков — свои, нарисованы процедурно.

## Сборка

```bash
./setup.sh                                            # Blender (bpy), Pillow, шрифт Unifont
./venv/bin/python scene.py --out frames --samples 32  # рендер кадров (~25–40 с/кадр на 4 ядрах CPU)
ELEVENLABS_API_KEY=... python3 voice.py --out voice   # озвучка (русские голоса ElevenLabs)
./venv/bin/python overlay.py --frames frames --voice voice/lines.json --out masstpa.mp4
```

Полезные флаги `scene.py`: `--frames 20,100,140` — отрендерить отдельные кадры для проверки,
`--res 360x640 --samples 8` — быстрый черновик, `--blend scene.blend` — сохранить сцену, чтобы открыть
её в Blender и доработать руками. `SKIP_EXISTING=1` — дорендерить только недостающие кадры.

## Файлы

- `scene.py` — мир (спавн, колодец, дом, деревья, облака), персонажи, анимация, камеры, рендер.
- `overlay.py` — цветокоррекция и свечение, чат русского сервера, подпись, ники, звуки + голоса, сборка mp4.
- `voice.py` — реплики персонажей через ElevenLabs (ключ берётся только из переменной окружения).
- `out/` — готовые ролики.

Шрифт: GNU Unifont (SIL OFL 1.1 / GPL с исключением для шрифтов), скачивается `setup.sh`.
